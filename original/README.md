# Original Raspberry Pi implementation

These are the original ARMv8 assembly source files supplied for the Raspberry Pi 3 bare-metal game. They are preserved separately from the browser port. The web app does not execute this assembly; its maze geometry and gameplay behavior are being reimplemented in TypeScript.

The original build also referenced a Makefile and linker script named `memmap`; those files were not included in the source attachments available during this port, so they are not recreated or guessed here.
