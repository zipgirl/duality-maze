# Duality Maze

A browser adaptation of the original Raspberry Pi 3 bare-metal ARMv8 maze game.

The web version preserves the two alternating maze worlds, their original wall layouts, trigger locations, and goal. The original assembly source will be kept alongside the web application.

## Development

```bash
npm install
npm run dev
```

## Controls

- Desktop: Arrow keys
- Mobile: On-screen directional pad
- Restart: Reset the game to its initial state

The game starts immediately; there is no timer or pause mode.
